# Результат конвертации и проверок текущего экспорта

> **Документ не относится к текущему `vanilla/`.** Ниже описана конвертация предыдущего экспорта (шрифт Exo 2, коммит `60a1569`) от 25 ноября 2026, результат которой позже был удалён. Текущий `vanilla/` (страница «Согласия…», Montserrat) собран из `source/` и проверен движком `tools/` (`check`, `unittest`, `browser-audit`, `compare`) — итоги в коммите `c6d984f`.

Дата: 25 ноября 2026. Вход: `source/` из Figma Make, содержимое коммита `60a1569e4e9afc38f6663b9c5e7ed1c2af284e1f`. Результат: `vanilla/`. Это конвертация **этого** экспорта, а не готовый универсальный автоматический преобразователь любых проектов.

## Что сделано

- Разметка получена из фактического браузерного рендера React и сохранена как HTML. JS вручную воспроизводит мобильное меню, раскрытие трёх карточек, активное состояние якорной навигации, сжатие шапки при прокрутке и обработку отсутствующих изображений. React и сервер разработки в готовом сайте не нужны.
- `css/style.css` — собранный CSS Tailwind v4 из исходного проекта, а не Tailwind runtime; исходные utility-классы намеренно сохранены для точности, CSS поэтому не является ручной семантической переработкой. Необходимые SVG и favicon скопированы без Windows-метаданных и LFS-указателей.
- Шрифт Exo 2 для четырёх исходных начертаний размещён локально из пакета `@fontsource/exo-2` 5.3.0, вместе с лицензией `vanilla/fonts/OFL.txt`. Сайт не требует Google Fonts при открытии. Эти небольшие файлы шрифта и favicon исключены из LFS через `vanilla/.gitattributes`, чтобы статическая поставка оставалась доступна после обычного клонирования. В метаданных указан русский язык и осмысленный заголовок; `noindex, nofollow` и `robots.txt` сохранены из исходной Figma-конфигурации.
- Старую `vanilla/` не удаляли без копии: перед заменой сохранены копии в `.work/backups/vanilla-before-conversion/` и `.work/backups/vanilla-original-moved/`, их отпечаток до замены совпадал с исходным `8a9df094fd44ec4a85ca6da5d135e58fc80dee8dc87699c9ce0c4ea736da9205`. В Git также остаётся версия до этой конвертации. Старые локальные LFS-указатели в копии не являются реальными бинарными объектами.

Это не побайтовое сравнение, не проверка всех устройств и не гарантия абсолютного pixel-perfect. Запрос исходного Google Fonts CDN в окружении недоступен; в эталонном браузере при проверке он был перехвачен и заменён локальным Exo 2 из того же пакета, поэтому оригинальная CDN-версия не проверена.

## Дополнительная проверка шрифтов

В исходном `source/src/index.css` объявлен Exo 2 из Google Fonts с обычным начертанием и весами 400, 500, 600, 700; в `vanilla/` подключены те же семейство и веса локально. Все 20 файлов WOFF2 в `vanilla/fonts/` побайтово совпали с файлами пакета `@fontsource/exo-2@5.3.0`. В Chromium все четыре веса для примера с кириллицей и латиницей загрузились через FontFaceSet; для заголовка через инструменты браузера подтверждено фактическое использование локального Exo 2 SemiBold. Это подтверждает проверенные файлы, веса и образец, но не доказывает совпадение каждого глифа и бинарных данных с текущим Google Fonts CDN: исходный CDN в этой среде недоступен. При визуальной сверке React и vanilla использовали одинаковые локальные файлы, а не оригинальный ответ CDN.

## Предупреждения и ограничения

- В исходном `public/images/logo.svg` файла нет. `public/images/site/mlogo.png` и `public/images/partners/bspb.png` — текстовые LFS-указатели, не доступные в виде изображений. `public/images/site/max.svg` содержит незакрытый CDATA и не декодируется браузером. Это **предупреждения, не блокер**: как и исходный React, готовая страница показывает запасные иконку и текст. Для исправления нужны действительные файлы; при их появлении по тем же путям JS загрузит их вместо fallback. Без JavaScript fallback остаётся видимым.
- Прогон производился на одном движке Chromium в текущем окружении. Реальные устройства, скринридер, все возможные ширины, внешние сайты, документы и телефонные вызовы не проверялись; ссылки не активировались во избежание внешних действий.
- Метрики относятся к доступному работающему React-экспорту, а не к оригинальному макету Figma. Ручной или автоматический аудит WCAG в полном объёме и проверка реального CDN Google Fonts не проводились. Часть общей инфраструктуры, описанной в плане, всё ещё не реализована.
