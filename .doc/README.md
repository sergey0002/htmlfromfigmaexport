# Документация проекта

Цель проекта — получать из React-экспорта Figma качественную статическую HTML/CSS-вёрстку с сохранением содержимого, адаптива и необходимого поведения, без React в финальном сайте.

**Текущее состояние: добавлены начальные универсальные инструменты инвентаризации и сравнения; автоматический конвертер и полная приёмка не реализованы.** Текущий React-исходник и сохранённая статическая версия относятся к разным сайтам. Не запускайте `node build.mjs` поверх существующей `vanilla/`: результат не соответствует даже сохранённой версии сайта. Подробности, результаты проверок и план работ — в [обзоре проекта](project-review.md).

Документы `00–07` и `report.md` сохранены как **исторические материалы**, а не как инструкция к текущему исходнику. Примеры путей, доменов, данных, метрик и SEO в них нужно проверять; нельзя автоматически переносить их в новый проект. Команда анализатора с `--write` перезаписывает `report.md` в указанном корне.

## Другие материалы в `.doc/`

- `scripts/` — анализатор и проверки; они не выполняют общую автоматическую конвертацию. Некоторые проверки зависят от Playwright/Chromium, а также от Pillow для пиксельного сравнения.
- `templates/` — две старые версии генератора для сайта клуба, не универсальные шаблоны.
- `screenshots/` — исторические снимки и результаты сравнения; часть файлов хранится через Git LFS.

Вне `.doc/` оставлены только специальные файлы инструкций `AGENTS.md` и `CLAUDE.md`: они должны оставаться в корне для инструментов, которые обнаруживают их по имени и расположению. Все остальные Markdown-документы проекта находятся в `.doc/`.
