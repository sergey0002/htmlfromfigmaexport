# `.doc/` — инструкции по конвертации Figma Make → чистый HTML

Этот документ — **инструкция для ИИ-агента**. Достаточно показать папку `.doc/` агенту и передать ему папку с исходником (экспорт Figma Make: React или Vue + Vite + Tailwind), чтобы он собрал из неё чистый, SEO-оптимизированный статический сайт без фреймворков.

## Старт: что делать с новым исходником

Если тебе (агенту) передали **папку с исходником** (например, `C:\проекты\новый-исходник\`) и эту папку `.doc/` — выполни следующие шаги по порядку. Подробности каждого шага описаны в документах `01–07`.

### Шаг 0. Разбор исходника

```powershell
# из корня проекта (где лежит переданный исходник)
python .doc/scripts/analyze_figma_export.py <корень-исходника> --write
```

Скрипт сам определит стек (React или Vue), прочитает `.figma/make/site.json`, соберёт все данные, изображения, Tailwind-классы и CSS-переменные в отчёт `.doc/report.md`. Прочитай его — это карта всего, что нужно перенести.

### Шаг 1. Копирование ассетов

Скопируй все изображения из `<исходник>/src/imports/` (или `src/assets/`) в `vanilla/img/`, приведи имена к `kebab-case.png`/`.jpg`.

### Шаг 2. Генератор страницы

Скопируй `.doc/templates/build.mjs` в корень проекта, открой и подставь данные из отчёта (`players`, `coaches`, `standings`, `partners`, `navItems` и т.д. — все массивы должны совпасть с исходником один-в-один). Затем запусти:

```powershell
node build.mjs   # сам создаст vanilla/ и сгенерирует vanilla/index.html
```

### Шаг 3. Стили и поведение

- Напиши `vanilla/css/style.css` по инструкциям `03-css-responsive.md` (токены, сетки, `minmax(0,1fr)`, `aspect-ratio` для фото, hover-эффекты, адаптив).
- Напиши `vanilla/js/app.js` по инструкциям `04-js-behavior.md` (скролл, бургер-меню, табы, подсветка активной секции, `IntersectionObserver`).

### Шаг 4. SEO-пакет

```powershell
python .doc/scripts/make_seo_pack.py --url https://site-url.ru/ --name "Название" --desc "Описание 130-170 симв." --email "email@site.ru"
```

Скрипт создаст фавиконы, `og-cover.png` и `seo-head.html` — вставь содержимое последнего в `<head>` генератора `build.mjs`, затем перезапусти `node build.mjs`.

### Шаг 5. Проверка

Двухступенчатая приёмка — обе должны показать 0 FAIL:

```powershell
# Статический анализ (код, файлы, SEO-разметка):
python .doc/scripts/check_vanilla.py vanilla --url https://site-url.ru/

# Браузерные тесты (реальный Chromium: сетки, скролл, шрифты ≥12px, меню, табы, hover):
# один раз установить: pip install playwright && playwright install chromium
python .doc/scripts/browser_test.py vanilla
```

WARN-сообщения допустимы только для файлов, которые должен предоставить заказчик (например, PDF-отчёты, реальные ссылки на соцсети). Открой сайт локально в браузере (через любой локальный сервер, не `file://`) и сверь с макетом в Figma на разрешениях 390 / 768 / 1024 / 1440 px.

### Шаг 6. Очистка

Убери из `vanilla/` все генераторы и служебные файлы (см. `06-deploy-checklist.md`). В поставке должны остаться только:

```text
vanilla/
  index.html      (готовый HTML с on-page SEO)
  css/style.css
  js/app.js
  img/…
  favicon.svg, favicon-16.png, favicon-32.png, apple-touch-icon.png, og-cover.png
```

### Шаг 7. Развёртывание

Скопируй **содержимое** `vanilla/` (не саму папку) в корень хостинга (`public_html/` или аналогичный). Сайт статический — ни Node.js, ни сборка на сервере не нужны. Детали в `06-deploy-checklist.md`.

## Принципы (обязательно соблюдать)

1. **Pixel-parity с макетом** — итоговая вёрстка должна визуально соответствовать дизайну из Figma.
2. **Чистый HTML без фреймворков** — ни React, ни Vue, ни Tailwind CDN в рантайме.
3. **On-page SEO обязателен** — title, description, OG/Twitter, JSON-LD, фавиконы, доступность.
4. **Относительные пути** (`./css/style.css`, `./img/…`) — сайт работает из любой подпапки.
5. **Ноль инлайн-стилей** — в HTML ни одного `style=`, весь дизайн через классы (02 §2.4);
   React-инлайны переносятся в классы/модификаторы `.is-*` и утилиты `.u-*`.
6. **Чистый CSS** — слои с русскими комментариями, ноль мёртвых классов, ноль дублей (03 §3.6).
6. **Читаемость на любых экранах** — минимальный шрифт ≥ 12px, h1 ≥ 32px на мобильном,
   fluid-типографика через `clamp`, `text-size-adjust: 100%` (03 §3.7).
7. **В `vanilla/` — только готовый сайт**; все генераторы и служебные файлы живут вне её.
8. **Проверка перед отдачей** — оба теста (`check_vanilla.py` + `browser_test.py`) показывают 0 FAIL.
