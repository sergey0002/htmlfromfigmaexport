# Документация проекта

Цель проекта — получать из React-экспорта Figma качественную статическую HTML/CSS-вёрстку с сохранением содержимого, адаптива и необходимого поведения, без React в финальном сайте.

**Текущее состояние: добавлены очередь страниц, частичная инвентаризация и проверки многостраничного сайта; автоматический конвертер, автоматическая приёмка и безопасная автоматическая публикация не реализованы.** Текущий `source/` — React SPA с несколькими hash-маршрутами; `vanilla/` в текущем checkout отсутствует. Очередь находится в `source/.work/PAGE-QUEUE.md`, её полнота ещё не подтверждена; текущее состояние инструментов описано в [tools.md](tools.md). План — в [multipage-implementation-plan.md](multipage-implementation-plan.md). Результаты коммита `c6d984f` относятся к другому исходнику («Согласия на обработку персональных данных»), а [vanilla-verification.md](vanilla-verification.md) — к ещё более ранней конвертации; ни то ни другое не подтверждает состояние текущего экспорта. Старый генератор `build.mjs` и его шаблоны удалены как наследие чужого клуба. Актуальные команды и ограничения — в [tools.md](tools.md); старый обзор и план помечены как исторические/проектные.

Для обычной браузерной сверки достаточно одного браузера — Chromium; дополнительные движки без отдельного запроса не требуются.

Документы `00–07` сохранены как **исторические материалы**, а не как инструкция к текущему исходнику. Примеры путей, доменов, данных, метрик и SEO в них нужно проверять; нельзя автоматически переносить их в новый проект. Команда анализатора с `--write` перезаписывает `report.md` в указанном корне (файл создаётся заново).

## Другие материалы в `.doc/`

- `scripts/` — анализатор и проверки; они не выполняют общую автоматическую конвертацию. Некоторые проверки зависят от Playwright/Chromium, а также от Pillow для пиксельного сравнения.
- `screenshots/` и `templates/` удалены (исторические снимки и генераторы клуба с персональными данными).

Специальные файлы инструкций `AGENTS.md` и `CLAUDE.md` остаются в корне для инструментов, которые обнаруживают их по имени. Основная документация проекта находится в `.doc/`; инструкции навыков — в `.agents/skills/`.
