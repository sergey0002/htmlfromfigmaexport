## 6.1. Итоговая структура поставки (эталон ФБК Таргет)

```text
vanilla/                    ← ТОЛЬКО готовый сайт, ничего лишнего
  index.html                (68 КБ, сгенерирован; правится через шаблон, не руками)
  css/style.css
  js/app.js
  img/…
  favicon.svg, favicon-16.png, favicon-32.png, apple-touch-icon.png, og-cover.png
```

Генератор `build.mjs` и всё служебное живут в `.doc/templates/`, а НЕ в vanilla.
Изменения в разметке = правка шаблона → регенерация → проверка.

## 6.2. Регенерация и локальное превью

```powershell
# Правки разметки = правка генератора (шаблон .doc/templates/build.mjs).
# Скопировать шаблон в корень проекта и запустить — он сам создаст vanilla/
# и запишет vanilla/index.html:
Copy-Item .doc/templates/build.mjs build.mjs
node build.mjs        # → vanilla/index.html

# Статика не требует сборки вообще. Превью:
npx --yes serve vanilla -l 8081      # http://localhost:8081
# или чистый Python без зависимостей:
python -m http.server 8081 --bind 127.0.0.1 -d vanilla
```

Важно: `file://` не работает (CORS для шрифтов/модулей) — только http-сервер.

## 6.3. Сборка React-версии (если нужна и она)

```powershell
# npm может быть заблокирован политикой выполнения скриптов PowerShell,
# тогда вызывать vite напрямую:
node node_modules/vite/bin/vite.js build --base=./ --outDir hosting
```

`--base=./` обязателен: относительные пути позволяют сайту работать
в любой папке хостинга. `hosting/` пересоздаётся целиком (старые хэш-файлы
автоматически удаляются).

## 6.4. Деплой на shared-хостинг (fbk-target.ru и аналоги)

1. Залить **содержимое** `vanilla/` (не саму папку!) в корень сайта
   (`public_html/`, `htdocs/` или аналог). Node.js на хостинге не нужен.
2. Файлы PDF (`otchetnost-ano-2026.pdf`, `ustav-ano.pdf`) кладёт заказчик —
   ссылки уже в футере; до появления файлов валидатор честно предупреждает WARN.
3. Ссылки-заглушки `href="#"` (ВКонтакте/Telegram) заменить на реальные URL
   до релиза.
4. HTTPS: включить сертификат (Let's Encrypt в панели хостинга),
   принудительный редирект http→https.
5. Кодировка: все файлы в UTF-8; `.htaccess` при необходимости:
   `AddDefaultCharset UTF-8`.

## 6.5. Финальный чек-лист перед отдачей

Автопроверки (см. 07-scripts.md):

```powershell
python .doc/scripts/check_vanilla.py vanilla --url https://fbk-target.ru/     # код/файлы/SEO
python .doc/scripts/browser_test.py vanilla                                   # реальный Chromium
```

Требуется один раз: `pip install playwright && playwright install chromium`.
Условие готовности: **0 FAIL в обоих**; WARN допустимы только с объяснением
(PDF заказчика, ссылки-заглушки соцсетей).

Браузерный тест автоматически проверяет на 390/768/1024/1440:
горизонтальный скролл, число колонок сеток, вылет элементов за вьюпорт,
загрузку всех локальных изображений (со скроллом для lazy), высоту фото
карточек (контроль «макушек»), минимальный шрифт ≥ 12px и h1 ≥ 32px,
контраст, бургер, Escape, закрытие меню по пункту, scroll-margin якоря,
табы, hover строк таблиц, подсветку активного раздела.

Пиксельный дифф с React-оригиналом (не обязателен, но ловит рассинхрон):

```powershell
node node_modules/vite/bin/vite.js build --base=./ --outDir hosting
python -m http.server 8090 --bind 127.0.0.1 -d hosting
python .doc/scripts/browser_test.py vanilla --diff-url http://127.0.0.1:8090/
```

Отклонение >3% — WARN (типографика читаемости и антиалиасинг шрифтов).
`--diff-strict` делает то же самое FAIL. Скриншоты пишутся в `.doc/screenshots/`.

Ручные проверки в браузере (Chrome DevTools, режим устройства):

- [ ] Мобильное меню: анимация fade+stagger, закрытие по пункту/кресту/Escape.
- [ ] Ctrl+F5 после деплоя (сброс кэша стилей).
- [ ] Lighthouse (портативный режим): Performance ≥ 90, A11y/Best Practices/SEO = 100.
- [ ] Валидатор https://validator.schema.org — JSON-LD без ошибок.
- [ ] Шаринг: превью с картинкой og-cover в мессенджерах/соцсетях.
- [ ] Таб-навигация: видимый золотой :focus-visible, skip-link работает с клавиатуры.

## 6.6. Типовые аварии (из реального диалога по этому проекту)

| Симптом | Причина | Лечение |
|---|---|---|
| Пустой экран при `file://` | `<script type=module>` + CORS | Только http-сервер |
| На хостинге пусто | Залит исходник Figma (`index.html` с `<!-- figma:* -->`) вместо сборки | Залить содержимое `vanilla/` |
| Картинки/стили 404 в подпапке | Абсолютные пути `/assets/…` | `--base=./` / относительные `./…` |
| Сайт не находится в поиске | Остался `noindex` из site.json Figma | Проверить meta robots = `index, follow` |
| Вёрстка «не обновилась» | Кэш браузера | Ctrl+F5; при релизах менять имена файлов |
| Карточки «одни макушки» | Фикс. высота фото + cover | `aspect-ratio` по пропорции фото |
| Сетка вылезает на 390px | `repeat(N,1fr)` вместо `minmax(0,1fr)` | 03 §3.3 |
| PowerShell: «выполнение скриптов отключено» | npm.ps1 заблокирован | `node node_modules/…` напрямую |
